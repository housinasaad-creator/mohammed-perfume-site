# MOHAMMED · Maison de Parfum

A scroll-driven luxury fragrance website — concept project.

The brand, products, prices and testimonials are fictional and exist only to showcase the design and front-end work.

- Scroll-scrubbed cinematic hero (canvas frame sequence with hold stops and a site-controlled zoom)
- Six hand-drawn SVG bottles in an interactive collection
- English / Arabic with a fixed left-to-right layout
- Plain HTML, CSS and vanilla JavaScript — no build step

Live: https://housinasaad-creator.github.io/mohammed-perfume-site/

Designed and developed by Muhammed Elhuseyin.
