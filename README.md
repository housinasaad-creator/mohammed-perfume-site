# MOHAMMED · Maison de Parfum

A scroll-driven luxury fragrance website — concept project.

The brand, products, prices and testimonials are fictional and exist only to showcase the design and front-end work.

- Five-stop cinematic hero: each scroll plays the film (canvas frame sequence) to the next hold frame with eased speed, while the title, zoom and camera focus change; embers fly with the film and float slowly when it stops
- Six-product collection with studio-style product shots (AI-generated concept imagery, hand-drawn SVG fallback)
- Custom brand cursor (flame, gold ring, embers) on devices with a mouse
- English / Arabic with a fixed left-to-right layout
- Plain HTML, CSS and vanilla JavaScript — no build step

Live: https://housinasaad-creator.github.io/mohammed-perfume-site/
